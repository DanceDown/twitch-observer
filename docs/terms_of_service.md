## What the bot provides

The bot can:

- track Twitch channels for a Discord context;
- observe public Twitch chat through Twitch IRC;
- match Twitch chat messages against configured ping or regex rules;
- forward matching messages to Discord;
- notify Discord about tracked Twitch live/offline changes;
- store per-context configuration and permissions;
- link a Discord user to a Twitch account through Twitch OAuth;
- send Twitch messages or auto-replies through a linked Twitch account when
  configured and authorized.
